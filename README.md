# TaskManager

Aplicación web para la gestión de tareas personales.

## Características
- Registro y autenticación de usuarios (simulado).
- Panel de control con resumen de tareas.
- Crear, editar y eliminar tareas.

## Tecnologías utilizadas
- HTML5, CSS3, JavaScript 
- Angular 
- Git y GitHubDesktop para control de versiones

## Estructura del proyecto
- `src/` - Código fuente de la aplicación.
- `public/` - Archivos estáticos.
- `README.md` - Documentación del proyecto.

## Contribuciones
Este proyecto sigue la estrategia de ramas Git Flow:
- `main` - Versión estable.
- `develop` - Integración continua.
- `feature/*` - Nuevas funcionalidades.
- `hotfix/*` - Correcciones urgentes.
